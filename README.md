# 🔬 ResearchLens – AI Research Paper Analyzer

ResearchLens is an AI-powered web application that helps users understand research papers easily. Users can upload a research paper, generate summaries and key insights, ask questions about the content, and receive relevant answers based on the uploaded document.

The application uses a **RAG (Retrieval-Augmented Generation)** approach to retrieve relevant information from research papers before generating answers. It supports **FAISS and Pinecone** for storing and retrieving document embeddings.

The frontend is built using **React**, while the backend uses **FastAPI and Python**. The application uses the **Groq API with LLaMA** for generating responses.

**Tech Stack:** Python, FastAPI, React, RAG, LangChain, FAISS, Pinecone, Groq API

✨ Features
📄 Upload and analyze research papers in PDF format
⚡ Generate structured paper summaries and key insights
💬 Ask questions about papers with citation-based answers
